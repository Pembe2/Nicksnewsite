# Visium Law Redesign

This branch contains a responsive raw HTML/CSS/JS redesign for Visium Law.

## Files
- `index.html` — homepage
- `styles.css` — responsive styles
- `script.js` — sticky header and mobile navigation
- `WIX-STUDIO-GUIDE.md` — instructions for recreating the design in Wix Studio

## Preview locally
Run `python3 -m http.server 8000` from the repository root, then open `http://localhost:8000`.

## Before production
Replace the NM placeholder with Nick McCrillis's approved headshot, replace the temporary V mark with the approved Visium logo, connect the consultation form to a secure form handler or Wix Forms, connect article cards to the live blog, and have the firm review legal claims, jurisdictional scope, privacy language, and attorney-advertising disclosures.
